## Terms

### Agentic Commerce

- 一句话解释：由 AI Agent 参与发现需求、比较选项、发起购买或交易，并在关键步骤接受人类授权或系统约束的商业流程。
- Web3/支付/交易/Agentic Commerce 语境：重点关注 Agent 能否安全理解支付意图、生成交易预览、遵守额度与权限、保留可审计记录。
